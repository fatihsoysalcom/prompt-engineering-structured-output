# Prompt Engineering Structured Output

This example demonstrates how prompt engineering can transform ambiguous AI model outputs into structured, machine-readable formats. It shows how a vague prompt leads to inconsistent text, while a well-engineered prompt explicitly requesting a specific format (like JSON) enables reliable programmatic parsing. This illustrates the article's concept of moving from "deceiving tricks" to a "real code-based solution" in prompt engineering.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
